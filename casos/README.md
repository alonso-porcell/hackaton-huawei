# Casos de uso

Esta carpeta reúne los casos de uso candidatos para la hackathon. Cada caso debe
vivir en su propia subcarpeta para que el equipo pueda comparar alternativas y
discutir el stack antes de comenzar la implementación.

## Casos disponibles

| Caso | Estado | Descripción |
| --- | --- | --- |
| [`api502`](./api502/) | Propuesta seleccionada | Recuperación autónoma de una API afectada por una configuración defectuosa de Nginx. |

Se pueden incorporar dos alternativas adicionales como carpetas hermanas de
`api502`.
